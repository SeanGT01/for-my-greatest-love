# Soundtrack & Music Notice

All soundtrack playback on this website is powered legally and royalty-free via **official YouTube Embeds** and an original Web Audio ambient chimes synthesizer.

Full songs play from start to finish without any 30-second preview limits or login requirements. No raw commercial audio files (MP3s) are hosted in this repository, ensuring 100% compliance with copyright and DMCA laws.

To customize the songs played on the site:
1. Open [`script.js`](../../script.js).
2. Edit the `PLAYLIST` array with your desired YouTube video IDs (found after `v=` in any YouTube link).
